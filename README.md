# Proyek Belajar Git

Ini adalah repositori untuk mempraktiikan materi **Version Control System**

## Fitur yang telah di pelajari:
- Dasar-dasar perintah Git dan Github
- Penanganan *Merge Conflict**
- Manipulasi sejarah kode (*rebase*, *Cherry-pick*, *squash*)

## Cara Menjalankan Proyek
Gunakan perintah berikut di terminal komputermu:

```bash
git clone [https://github.com/alfaridhafizh/belajar-git-2.git](https://github.com/alfaridhafizh/belajar-git-2.git)
cd belajar-git-2
```
